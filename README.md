Плагин автоматизации, чистки True Color (RGB) цветов и сплющивания 3D-объектов (Z=0) для nanoCAD 5.1 на .NET 3.5.
# SunRise-nanoCAD-Plugin

**SunRise** — это бесплатное .NET-расширение (плагин) для автоматизации, глубокой очистки и исправления проблемных чертежей в **nanoCAD 5.1**. Проект разработан на базе **.NET Framework 3.5** и библиотеки **Teigha API**, что обеспечивает полную совместимость со старыми сборками САПР.

Плагин разработан для решения частых «болей» проектировщиков и CAD-менеджеров при работе с файлами DWG, экспортированными из других систем (AutoCAD, Revit, Компас-3D и др.).

---

## 🚀 Основные возможности и команды

После загрузки плагина в nanoCAD вам станут доступны следующие команды (регистр букв не важен):

### 1. `FlattenDrawing` (Сплющивание чертежа)
Принудительно проецирует все графические объекты на плоскость **Z = 0**. Решает проблему «вертолетов» (объектов, случайно улетевших в 3D-пространство), из-за которых ломаются привязки, размеры и подсчет площадей.
* **Что обрабатывает:** Отрезки (`Line`), Полилинии (`Polyline`), Сплайны (`Spline`), 3D-полилинии (`Polyline3d`), Тексты (`DBText`, `MText`), Окружности и Дуги (`Circle`, `Arc`), Вхождения блоков (`BlockReference`), Точки (`DBPoint`), Размеры (`Dimension`), Штриховки (`Hatch`).
* **Особенность:** Умеет рекурсивно находить и приземлять на ноль **мультивыноски (`MLeader`)** и **скрытые атрибуты внутри блоков**, которые часто игнорируются стандартными средствами. Сдвиг происходит через безопасные матрицы смещения, не искажающие геометрию.

### 2. `ConvertToMText` (Объединение и конвертация в МТекст)
Объединяет однострочные тексты в один многострочный (`MText`), если выбрано несколько однострочных текстов (`DBText`), порядок строк в новом (`MText`) зависит от порядка выбора (`DBText`). Если выбран только один (`DBText`), то он просто преобразуется в один (`MText`)
* **Что обрабатывает:** Однострочные тексты (`DBText`)

### 3. `FixTrueColors` (Глубокая очистка True Color / RGB палитры)
Сторонние САПР часто записывают цвета слоев и рамок таблиц в формате RGB (например, `255,128,0`), из-за чего встроенные стили печати (такие как `monochrome.ctb`) игнорируют их, и чертеж выводится на бумагу цветным.
* **Что делает:** Находит True Color цвета и автоматически переводит их в ближайшие стандартные индексные цвета палитры **ACI (AutoCAD Color Index)** от 1 до 256. На экране чертеж остается цветным и удобным для работы, но при ч/б печати все элементы гарантированно сжимаются в черный цвет.
* **Область очистки:** Слои чертежа, отдельные объекты модели/листов, скрытые теги RGB-форматирования внутри Мультитекста (`MText`), а также тексты в ячейках встроенных **Таблиц nanoCAD (`Table`)**.

### 4. `SunRiseInfo`
Выводит в консоль справочную информацию о плагине, текущую версию и список доступных инструментов.

### 5. Дополнительные утилиты (в разработке / бета):
* `CheckDisk` — быстрая проверка СМАРТ-статуса жесткого диска.
* `PaintItBlack` — тотальное перекрашивание элементов в черный цвет.

## ⚙️ Автоматическая инициализация

Плагин использует интерфейс `IExtensionApplication` и атрибуты сборки. Это значит, что при ручной загрузке через команду `NETLOAD` (или при настройке автозагрузки nanoCAD) метод инициализации запускается **автоматически**. В консоли появится приветственное сообщение:  
`[SunRise]: Расширение успешно загружено и инициализировано!`

## 🛠️ Разработка и компиляция

Для сборки проекта вам понадобятся:
1. **IDE:** Visual Studio (рекомендуется версия с поддержкой старых таргетов .NET).
2. **Target Framework:** `.NET Framework 3.5` (критично для nanoCAD 5.1).
3. **Ссылки (References):** Из корневой папки установленного nanoCAD 5.1 необходимо подключить две основные управляемые библиотеки (свойство *Copy Local* выставить в *False*):
   * `HostMgd.dll`
   * `Teigha.CoreMgd.dll` (или аналогичные библиотеки базовых классов геометрии и базы данных Teigha, поставляемые с SDK).
